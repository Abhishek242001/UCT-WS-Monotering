Enroll from a dataset zip

Use this for photos taken at several distances, such as a calibration shoot. Upload one zip per employee. Every view at the closest distance is enrolled straight away, and the zip is kept so Train model can use all the distances.

Folder layout inside the zip. The folder name can be anything, because the employee is matched by the ID entered above.

Train model

Fits the distance-matching curve (near_k and near_sigma0) from every employee enrolled by zip who has two or more distances. Safe to run again, for example after enrolling more people.

Run detection on one photo

Uploads a still image, finds people with YOLO inside the saved region of the workstation you name, then tries to match the face against enrolled employees. It stands in for what a live camera frame would trigger.

Start a stream

Point the server at an RTSP URL, or at a video file path on the server (not a file from this browser). Occupancy is checked on every frame. A face is identified when a desk goes from vacant to occupied, then again every 60 seconds, or every 5 seconds while the last result was UNKNOWN. To try it without a camera, use ../sample_data/demo-camera-feed.mp4.
