Bulk enroll from a dataset zip

For datasets captured at multiple distances (like a calibration shoot). Upload one zip per employee; every view (front/left/right/top) at the closest distance is enrolled immediately, and the zip is kept so "Train model" below can use every distance to fit the distance-matching curve.

Expected folder layout inside the zip (folder name can be anything -- matched to the Employee ID above, not the folder name):

your-upload.zip
└── <any-folder-name>/
    ├── depth_000.50m/
    │   ├── front.jpg
    │   ├── left.jpg
    │   ├── right.jpg
    │   └── top.jpg
    ├── depth_001m/
    │   └── ... same 4 files
    └── depth_002m/
        └── ... same 4 files

Try it: run real detection on a photo

Uploads a still image and runs the real YOLO person-detector against your saved ROI, then attempts face matching against enrolled employees. This simulates what a live camera frame would trigger — see backend/app/routers/workstations.py for exactly what runs.

Start a real stream-processing worker

Points the real backend at an RTSP URL or a video file path on the server (not a browser upload). It opens the source, runs YOLO occupancy detection on every frame, and identifies people using the event-driven trigger — only on a VACANT→ACTIVE transition or the heartbeat, never every frame. Try ../sample_data/demo-camera-feed.mp4 to see it work end to end without a real camera.
