# this environment pulled in plain opencv-python alongside the headless
# one already here, and it went unnoticed until explicitly checked for.
# ultralytics' own package metadata asks for "opencv-python" by name --
# that's a harmless pip resolver warning, not a real missing dependency,
# since the actual import (`cv2`) is satisfied by the headless package.
